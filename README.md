# VARCO Sound

[VARCO Sound](https://sound.varco.ai) 웹 계정으로 AI가 **게임 사운드(SFX·앰비언스·폴리·음악)를 생성**하고, 사람은 생성된 후보를 **듣고 골라** 게임 폴더에 저장합니다. 별도 API 키 없이 웹 로그인 한 번이면 됩니다.

## 처음 한 번
AI가 도구를 처음 쓰거나 사이드바 **VARCO Sound**에서 **VARCO 로그인**을 누르면 로그인 창이 뜹니다. 로그인하면 창이 자동으로 닫히고 세션이 저장됩니다.

## 여러 사운드를 골라서 만들기 (`varco_sound_batch`)
1. "이 게임에 필요한 사운드 만들어줘" → AI가 사운드마다 이름, **사용 위치**, 영어 프롬프트, 파일명을 정해 한꺼번에 생성합니다(동시 3개).
2. VARCO Sound 화면이 **검토 모드**로 열리고 항목을 하나씩 보여 줍니다: 사용 위치 설명 + 후보 1·2·3 재생, 추천 표시.
3. **이걸로 선택** → 다음 항목. **다시 생성**(프롬프트 수정), **건너뛰기**, 이전/다음.
   단축키: `1`·`2`·`3` 재생, `Enter` 마지막에 들은 후보 선택, `←`/`→` 이동, `S` 건너뛰기.
4. **저장하고 완료** → 고른 후보만 지정 폴더에 지정 파일명 WAV로 저장, AI는 결과 경로를 받아 이어서 작업합니다.
- **남은 항목 자동선택** / **전체 자동선택 후 저장**, 또는 AI에게 "알아서 골라"(`autoSelect: true`).

## 그 밖의 도구
`varco_sound_generate`(1개 생성·저장), `varco_sound_list`, `varco_sound_get`, `varco_sound_download`(고른 후보만 저장), `varco_sound_status`(로그인·크레딧 비용), `varco_sound_review`(검토 상태), `varco_sound_show`.

## 화면
사이드바 **VARCO Sound** / 오른쪽 **사운드** 패널: 프롬프트로 직접 생성, 전체 목록 검색, 후보 바로 듣기, **저장**(WAV), **웹**(웹 편집기에서 열기).

## 설정
기본 저장 폴더 `음악\VARCO Sound` (설정 → 플러그인 → VARCO Sound → "저장 폴더"). AI는 호출마다 `saveDir`로 Unity `Assets/Audio/...`를 직접 지정할 수 있습니다.

> 생성에는 VARCO Sound 계정 크레딧이 듭니다(텍스트→사운드 1회 50 크레딧, 후보 3개). 웹 서비스의 내부 API를 쓰므로 서비스가 바뀌면 업데이트가 필요할 수 있습니다.
